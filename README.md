## 프로젝트 개요
- **프로젝트 이름**: 2D Platformer
- **프로젝트 기간**: 2025.01.14 - 2025.01.21
- **팀 구성**: 개인 프로젝트
<br><br/>

## 프로젝트 목표
이 프로젝트는 Unity에서 제공하는 무료 Asset Package를 사용하여 만든 2D Platformer 게임입니다.

첫 Unity 개발 프로젝트로서, 미리 준비된 에셋을 활용하여 Unity에 적응하고 개발 과정을 익히는 것을 목표로 합니다.
<br><br/>

## 플랫폼 및 기술 스택
- **게임 엔진**: Unity 2022.3.20f1
- **프로그래밍 언어**: C#
- **플랫폼**: PC
<br><br/>

## 게임 목표
총 4개의 Level로 이루어져 있으며, 캐릭터를 조작하여 해당 Level의 목표를 달성하여 다음 Level로 넘어가는 것이 목표입니다.
<br><br/>

## 게임 주요 기능
- **캐릭터 이동**: A, D 키로 좌우 이동
- **점프**: Space 키로 점프
- **일시 정지**: Escape 키로 일시 정지
- **발사체 발사**: 발사체를 획득한 후 마우스 왼쪽 클릭으로 발사 (적에게 충돌 시 적 제거)
- **레벨 재시작**: 땅 아래로 떨어지거나 체력이 모두 닳을 경우 해당 레벨 재시작
- **진행도 저장**: 플레이했던 레벨의 진행도 
<br><br/>

## 사용한 Asset
사용한 Package File이 현재 Asset Store에서 내려간 상태이기에 다운이 불가능합니다.

Image File들은 저작권 관련 문제가 발생하는 것을 방지하기 위해 업로드에서 제외했습니다.
